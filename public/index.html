GAME

The 80% Game

A social-deduction number game in the spirit of Alice in Borderland's elimination rounds — guess a number, chase 80% of the average, and watch the rules escalate as players get knocked out.

See the full ruleset

Base Game

Always Active

Each player picks a number from 0–100. The target is 80% of the average. Closest to the target wins the round. You MUST submit before the timer runs out!

Winner: -0 (no penalty) · Others: -1

Rule 1: Duplicate Guard

After 1 elimination

If 2+ players choose the same number, that number is INVALID. Those players each lose -1 and are excluded from winning.

Duplicates: -1 (invalid) · Remaining scored normally

Rule 2: Double Penalty

After 2 eliminations

If a player guesses the EXACT target number, all other players lose -2 instead of -1. The exact match winner gets -0.

Exact winner: -0 · Others: -2

Rule 3: Zero/Hundred Override

After 3 eliminations

Only when 2 players remain. You MUST pick 0, 1, or 100 — no other numbers allowed. Rock-paper-scissors decides: 100 beats 0, 0 beats 1, 1 beats 100. Same pick = tie (both lose -1).

RPS Winner: +0 · Loser: -1 · Tie: -1 each
